# Pokemon Jade

Jade is a romhack based off the CSE engine for Pokecrystal.

## Planned Features

- **350 pokemon** There will eventually be around 350 pokemon (all gens 1+2) and ~100 selected from later generations thanks to the Extended 16-bit Indexes featured in CSE
- currently 1 new pokemon has been added (Falinks) credit to u/SageDeoxys on reddit for the sprite
